# Snake Game em Python

Um jogo clássico da cobrinha desenvolvido em Python utilizando Pygame.

Este é o meu **primeiro projeto em desenvolvimento de jogos**.  
O objetivo foi colocar em prática meus conhecimentos de Python e aprender os conceitos básicos de desenvolvimento de jogos, como movimentação, colisões, pontuação e controle de eventos.

## Tecnologias

- Python
- Pygame
